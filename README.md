# 四时花开

立体水墨交互作品展示。首页提供作品介绍和预览，编辑器可载入四个花篮模型，调整视角、位置、旋转、缩放和水墨呈现效果，并导出 PNG。

## 访问

GitHub Pages: https://chenjin0403.github.io/four-seasons-portfolio/

电脑推荐使用最新版 Chrome 或 Edge；手机提供响应式布局。摄像头手势功能需要浏览器授权。

## 部署

纯静态网站，使用 GitHub Pages，从 main 分支根目录发布；无需构建。请保留 vendor 目录内的第三方许可证。

网页版本不包含依赖本机 ComfyUI 的模型生成服务。原作品文件未修改。
